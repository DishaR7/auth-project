# Authentication System

A full-stack authentication application built with **FastAPI, React, and PostgreSQL**.

## Features
- User registration and login
- JWT access and refresh tokens
- Password hashing
- User profile viewing and updating
- Password changes
- Role-based access control
- Admin-only endpoint
- Account deletion

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **Authentication:** JWT
- **ORM:** SQLAlchemy
